도메인과 DNS란 무엇인가?
+DNS 서버가 고장나면 웹사이트 접속은 어떻게 될까?

쉽게 정리하면

IP 주소: 건물의 실제 주소
도메인: 건물의 이름
DNS: 건물 이름을 검색해서 실제 주소를 알려주는 전화번호부

라고 할 수 있습니다

DNS는 도메인 이름을 IP 주소로 변환해서 컴퓨터가 서버를 찾도록 도와주는 시스템입니다.
DNS 서버에 문제가 생기면 도메인 이름으로 웹사이트를 찾지 못할 수 있습니다.
도메인 > DNS 서버 장애 > IP 주소를 찾지 못함 > 웹사이트 접속 실패
다만, DNS 서버가 고장 났다고 웹사이트 서버까지 고장 난 건 아니므로 ip주소로 접근하거나, 
이미 DNS정보가 저장되어 있거나, 다른 DNS서버를 이용하면 접속이 가능합니다.
