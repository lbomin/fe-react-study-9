주말 학습 과제 - React 학습을 위한 웹 기초

다음 주부터 React를 학습합니다.
React는 웹 애플리케이션을 개발하기 위한 기술이므로 기본적인 웹의 동작 방식과 HTML/CSS에 대한 이해가 필요합니다.
이번 주말에는 다음 내용을 스스로 조사하고 직접 실습해 보세요.

1. 웹의 기본 동작 원리 알아보기

다음 용어가 무엇을 의미하는지 조사하고 자신의 말로 간단하게 정리하세요.

클라이언트(Client)
서버(Server)
IP 주소
포트번호
URL
웹 브라우저

각각의 용어만 따로 암기하기보다는 다음 상황을 생각하면서 서로 어떤 관계가 있는지 알아보세요.

2. HTML 기본 알아보기
HTML이 무엇이며 웹페이지에서 어떤 역할을 하는지 조사하세요.
그리고 다음 HTML 태그의 용도와 사용 방법을 알아보세요.

기본 구조 및 콘텐츠

h1 ~ h6 : 제목
p : 문단
div : 영역 구분
span : 인라인 영역
a : 링크
img : 이미지

목록
ul : 순서가 없는 목록
ol : 순서가 있는 목록
li : 목록의 항목

입력 및 버튼
input : 사용자 입력
button : 버튼
form : 입력 양식

표(Table)
table : 표 전체
tr : 표의 행
th : 표의 제목 셀
td : 표의 데이터 셀

각 태그를 단순히 조사하는 것에서 끝내지 말고 직접 HTML 파일을 만들어 사용해 보세요.

특히 table, tr, th, td를 이용하여 간단한 표를 직접 만들어보고 브라우저에서 어떻게 나타나는지 확인하세요.


3. CSS 기본 알아보기
CSS가 무엇이며 HTML과 어떤 관계가 있는지 조사하세요.
다음 CSS 속성을 직접 사용해 보세요.

color
background-color
width / height
margin
padding
border
font-size
display

가능하다면 display: flex를 사용했을 때 화면이 어떻게 달라지는지도 확인해 보세요.

4. AI 활용

ChatGPT, Gemini 등의 생성형 AI를 학습에 활용해도 됩니다.
단순히 정답이나 완성된 코드를 요청하기보다는 모르는 내용을 구체적으로 질문하고, 작성된 코드는 직접 실행하여 결과를 확인하세요.

예시 질문
"서버와 클라이언트의 관계를 웹사이트에 접속하는 상황을 예로 들어 쉽게 설명해줘."
"HTML의 div와 span의 차이를 실제 코드 예제와 함께 설명해줘."
"HTML의 table, tr, th, td가 각각 어떤 역할을 하는지 예제와 함께 설명해줘."
"CSS에서 margin과 padding의 차이를 쉽게 설명해줘."
